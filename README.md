# ミノログ

ぷよぷよテトリス2 の対戦の録画(mp4)から、1手ずつの棋譜(置いたミノ・場所・向き・HOLD・消したライン・お邪魔)を自動で作る Windows 用のソフトです。

**アルファ版です。** 無料で使えます。株式会社セガ・The Tetris Company とは関係のない、個人が作った非公式のソフトです。

## ダウンロード

[Releases](../../releases) から `ミノログ_v0.1.2-alpha.zip` を落としてください。

## できること

1. 録画をコマに分けて、画面から手を読み取ります。
2. 読み取れなかった手を、前後のコマから解き直して埋めます。
3. HOLD の入れ替えの見落としを直します。
4. 棋譜と、1手ずつ盤面を見られるレポートを作ります。

9本の録画・約5万手(49,973手)で試したところ、99.5%(49,738手)が棋譜になりました。読み取れなかった手は、推測で埋めずに空けてあります。解き直して埋めた手のうち、百手に1手ほどは誤りを含みうる見込みです。

## 使える録画

- PC 版のぷよぷよテトリス2 を、1920x1080 のフルスクリーンで録画したもの
- 対戦で、左側(1P)がテトリスの盤面
- 1秒に2手近い速さの手や、とてもゆっくり動かした手は読めないことがあります

## 使い方

1. zip を展開します。
2. 最初に1回だけ `セットアップ.bat` をダブルクリックします。.NET 9 と Python が無ければ、入れるか聞きます。
3. `ミノログ.bat` に録画をドラッグ&ドロップします。
4. 終わると `入口.html` が開きます。

時間は録画の長さの約10倍かかります(5分の録画で約10分、37分の録画で約10時間)。流している間は、録画のファイルの約4.5倍の空きが要ります。終わると数十MBになります。

## 動作環境

- Windows 10 / 11(64ビット)
- .NET 9 デスクトップ ランタイム、Python 3.10 以上(セットアップが確かめます)

作者の PC 以外での動作は、まだ十分に確かめていません。セットアップで止まったら、Issues で教えてください。

## 不具合の報告

[Issues](../../issues) に、zip の中の `版.txt` と、結果のフォルダーの `記録_ミノログ.txt` を添えて送ってください。

## 利用条件とライセンス

zip の中の `利用条件.txt` を読んでください。ほかの人が作った部品(OpenCV・OpenCvSharp・FFmpeg)のライセンスは、zip の中の `ライセンス` フォルダーにあります。
