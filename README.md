# ミノログ

日本語 | [English](README.en.md)

ぷよぷよテトリス2 の対戦の録画(mp4)から、1手ずつの棋譜(置いたミノ・場所・向き・HOLD・消したライン・お邪魔)を自動で作る Windows 用のソフトです。

**ベータ版です。** 無料で使えます。株式会社セガ・The Tetris Company とは関係のない、個人が作った非公式のソフトです。

## ダウンロード

[Releases](../../releases) から最新の `minolog_v….zip`(いまは `minolog_v0.2.2-beta.zip`)を落としてください。

.NET や Python を PC に入れたくないときは、同じページの同梱版 `minolog_v…_portable.zip`(約 242MB。0.1.17 から)を落としてください。.NET 10 と Python が中に入っていて、セットアップが要りません。

## できること

1. 録画をコマに分けて、画面から手を読み取ります。
2. 読み取れなかった手を、前後のコマから解き直して埋めます。
3. HOLD の入れ替えの見落としを直します。
4. 棋譜と、1手ずつ盤面を見られるレポートを作ります。

7本の録画(左右を別に数えて9盤面)・約5万手(49,973手)で試したところ、99.5%(49,738手)が棋譜になりました。読み取れなかった手は、推測で埋めずに空けてあります。解き直して埋めた手のうち、百手に1手ほどは誤りを含みうる見込みです。本解析が画面から読んだ手にも誤りがありえます(1本の録画で調べたところ 263 手中 9 手。多くは HOLD の入れ替えの見落としで、回収の段で HOLD を直す前の数字です)。

## できないこと・確かめていないこと

- ぷよぷよの盤面は読めません。対戦でない録画(40LINE など)は確かめていません。
- 低い画質の録画では、違う手が混ざります(棋譜の中では見分けられません)。元の 1920x1080 の録画を使ってください。
- 録画そのものが飛んだ所(録画中に PC が重くなると起きます)の手は、あとから戻せません。
- 「悪手」は参考です。相手の攻撃や試合の流れは見ていません。
- 作者の PC(Windows 11 の 1 台)のほかで、通して流した記録はまだありません。Windows 10・管理者でないアカウント・OneDrive の下・インターネットにつながらない PC では、確かめていません。
- くわしくは zip の中の `読んでください.txt` の「分かっている制限と、確かめていないこと」と「よくある質問」にあります。

## 使える録画

- PC 版のぷよぷよテトリス2 を、1920x1080 のフルスクリーンで録画したもの(作者の録画は 60fps・約 13 Mbps。10 Mbps 以上をおすすめします)
- 対戦の録画。左側(1P)・右側(2P)・両方のどれを読むかを始めに選びます(読む側がテトリスの盤面であること)
- とても速い手や、とてもゆっくり動かした手は読めないことがあります(これまで読めた速い録画は、1秒に約2.4手まで)
- YouTube の動画も、URL を貼れば使えます(0.2.1 から。1080p で上がっているもの)。元の録画より違う手が増えます(17分の録画で約 2.5〜2.8%)。元の録画があれば、そちらを使ってください

## 使い方

1. zip を右クリック →「すべて展開」で展開します(zip の中から開かないでください。ほかのファイルが見つからずに止まるか、結果が一時の場所に書かれるおそれがあります)。
2. `ミノログ.exe` をダブルクリックします(窓で使う。0.1.15 から)。初めてのときは「最初の準備をする(1回だけ)」を押します。.NET と Python が無ければ、入れるか聞きます。
3. 録画を窓にドラッグ&ドロップし、読む側(1P・2P・両方)を選んで「棋譜にする」を押します。
4. 終わると `入口.html` が開きます。

窓を使わないときは、最初に1回だけ `セットアップ.bat` を流し、`ミノログ.bat` に録画をドラッグ&ドロップします(読む側は番号で選びます。1 = 1P、2 = 2P、3 = 両方)。

ブラウザーで落とした zip は、展開する前に zip を右クリック →「プロパティ」→ 下の「許可する」に印を付けて「OK」を押すと、.bat や exe を開くときの「Windows によって PC が保護されました」という警告が出にくくなります。出たときは「詳細情報」→「実行」で開けます(ミノログには署名が付いていないためです)。

時間は片側で、5分の録画なら10分前後、25分の録画なら2〜3時間ほどです。1つの試合が長いほど延び、長い試合を含む37分の録画では約10時間かかりました。両方を選んでも、1P の回収と 2P の本解析を同時に進めるので2倍よりは短く済みます。流している間は、録画のファイルの約4.5倍の空きが要ります。終わると数十MBになります。

## 動作環境

- Windows 10 / 11(64ビット)
- .NET 9 以上のデスクトップ ランタイム、Python 3.11 以上(セットアップが確かめます。無いときに入れるのは、0.2.0 から .NET 10 です)
- セットアップにはインターネットが要ります。つながらない PC では、同梱版 `minolog_v…_portable.zip` を使ってください
- 管理者として実行する必要はありません(セットアップが .NET や Python を入れるときに、Windows が許可を求めるかは確かめていません)

作者の PC 以外での動作は、まだ十分に確かめていません。セットアップで止まったら、Issues で教えてください。

## 不具合の報告

zip の中の「診断を作る.bat」で作った診断ファイル(minolog_diag_….zip)を添えてもらえると、原因を追いやすくなります(0.1.12 から)。

[Issues](../../issues) に、zip の中の `版.txt` と、結果のフォルダーの `記録_ミノログ.txt` を添えて送ってください。

## 利用条件とライセンス

zip の中の `利用条件.txt` を読んでください。ほかの人が作った部品(OpenCV・OpenCvSharp・FFmpeg・Cold Clear)のライセンスは、zip の中の `ライセンス` フォルダーにあります。

「ぷよぷよ」はセガの、「テトリス(Tetris)」は Tetris Holding の商標です。
